# Coastal Tulunadu Invitation Website

## Quick setup
1. Open `index.html` and replace the placeholder names, dates and venue.
2. Open `script.js` and update `WEDDING_DATE`, calendar title/location/description.
3. Put your photographs in the `images` folder using the filenames:
   - couple-1.jpg
   - photo-1.jpg through photo-6.jpg
4. For music, put an MP3 at `images/music.mp3` and uncomment the `<source>` line in `index.html`.
5. Replace the Google Maps URL in `index.html` with your venue's Google Maps link.
6. Upload the whole folder to a GitHub repository and enable GitHub Pages.

The page is designed mobile-first and does not require a server or database.
